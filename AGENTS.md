# 5gor-new

Порт игры «5GOR — такси в Пятигорске» с Three.js на **Godot 4.7**.

Оригинал: `~/Desktop/_JS/5gor` — ~18.5k строк JS, вся графика и звук
процедурные, внешних ассетов нет. Здесь воспроизводится весь его функционал
с улучшенным low-poly визуалом; город остаётся узнаваемым Пятигорском.

Собирается **одним билдом под три платформы**: Desktop (Forward+),
Mobile, Web (Compatibility).

## Мета

Перед добавлением или изменением правил, скилов, инструкций -- прочитай скилл

## Правила

### Данные генерируются, а не пишутся руками
`data/**/*.tres` и `assets/i18n/game.csv` — артефакты конвейера
`tools/dump_data.mjs` → `tools/import_json.gd`. Ручные правки затираются.
[Подробности](.agents/rules/data-pipeline.md)

### Кодстайл GDScript
Статическая типизация с варнингами-как-ошибками, комментарий объясняет «почему»,
у каждого состояния один владелец, чистая логика отделена от дерева сцены.
[Подробности](.agents/rules/gdscript-style.md)

### Рендер и визуальный стиль
Три рендерера одним билдом, `MeshBuilder` и MultiMesh, известные ловушки
(запись в `ALPHA` убивает тени, сглаживание нормалей ломает low-poly).
Проверка результата — только снимком.
[Подробности](.agents/rules/rendering.md)

### Тесты
gdUnit4 headless. Тест — исполняемая спецификация: сверка с оригиналом,
инварианты ПДД, бюджеты производительности.
[Подробности](.agents/rules/testing.md)

## Структура

```
autoload/   Bus, Db, Prefs, Game, Audio, Inp, Dir
schema/     классы Resource + каталоги
data/       сгенерированные .tres
core/       MeshBuilder, SeededRng, SpatialHash2D, MathUtils, RenderCaps, Heading
world/      city (поля, графы, планировщик, мешер, сборщик), sky
fx/         шейдеры и материалы
tools/      конвейер данных, съёмщик кадров, прогон тестов
tests/      unit, scenes (полигоны для снимков)
```
