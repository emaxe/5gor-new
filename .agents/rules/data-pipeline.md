# Данные генерируются, а не пишутся руками

`data/**/*.tres` — **сгенерированные артефакты**. Править их вручную нельзя:
следующая перегенерация затрёт правки.

## Как это работает

```
~/Desktop/_JS/5gor/src/*.js      исходный баланс игры
        ↓  node tools/dump_data.mjs
tools/dump/*.json                 промежуточный дамп (gitignored)
        ↓  godot --headless --path . --script res://tools/import_json.gd
data/**/*.tres                    ресурсы Godot
assets/i18n/game.csv              все пользовательские строки
```

`dump_data.mjs` вырезает константы из JS-текста балансировкой скобок — модули
оригинала тянут three.js и DOM, импортировать их напрямую нельзя.

## Правила

- Меняется баланс — правится **таблица в `tools/import_json.gd`** (если значение
  наше) либо оригинал и запускается перегенерация (если значение оттуда).
- Все пользовательские строки идут через `_tr_key()` в CSV. В ресурсах остаются
  только ключи локализации, в сценах — ни одной русской строки.
- Схемы ресурсов живут в `schema/`, каталоги — в `schema/catalog/`.
- `*Data`-ресурсы **read-only во время игры**. Присваивание их полям вне
  `tools/` и `tests/` — ошибка ревью: `load()` возвращает один общий экземпляр,
  и правка «одного врага» изменит всех. Мутируемое состояние живёт в
  отдельных `RefCounted` (`CarRuntime`, `OrderRuntime`).
- Числа сверяются с оригиналом тестом `tests/unit/test_data_integrity.gd` —
  ошибка в мэппинге не упадёт при запуске, а тихо сломает баланс.
