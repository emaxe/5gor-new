# Тесты

gdUnit4, headless. Запуск:

```
tools/run_tests.sh              # всё
tools/run_tests.sh tests/unit/test_city_field.gd
```

## Что покрывается

Тест здесь — не формальность, а **исполняемая спецификация**. Три категории:

1. **Сверка с оригиналом.** Рельеф, экономика, пороги дрифта, стоимости рёбер
   графа сверяются с эталоном, снятым прогоном чистых функций JS в Node
   (`tools/dump/terrain_ref.json`). Ошибка в порте не падает — она тихо
   меняет баланс.

   С плана `docs/plans/real-city/` (этапы 1-10) город больше не строится по
   сетке 9x9 оригинала — топология улиц, число узлов/перекрёстков, форма
   кварталов и расписание светофоров КАК ТАКОВОЕ (структура фаз, число фаз
   на узел) сверке с оригиналом больше не подлежат: у произвольного графа
   Пятигорска нет сеточного аналога в citygen.js, сверять не с чем. Эти тесты
   стали проверкой **внутренней согласованности** новой модели (граф связен,
   инварианты ПДД держатся, детерминизм от `world_seed` сохраняется), а не
   числовым сравнением с JS. Арифметика, которая от топологии НЕ зависит
   (цикл светофора 16 с, доли зелёного/жёлтого, скорость зелёной волны —
   `world/city/graph/node_signal_controller.gd`, `CYCLE`/`YELLOW_FRACTION`/
   `WAVE_SPEED`), остаётся портом citygen.js и сверяется по-прежнему — не
   напрямую с JS, а через паритет с осевым `TrafficLightController`
   (сохранён намеренно как эталон-фикстура; `tests/unit/test_traffic_lights.gd`,
   `tests/unit/test_node_signals.gd:test_grid_node_matches_axis_controller`),
   который сам был портом этих же констант и в живой игре больше ничем не
   используется.
2. **Инварианты правил.** Главный: «ни один участок маршрута без гейта не
   пересекает проезжую часть». Именно он поймал дефект оригинала, где
   тротуарные узлы стояли по центру пересекающей дороги.
3. **Бюджеты.** Время планирования города, стоимость `height_at`, число
   маршрутов в секунду, отсутствие orphan-узлов.

## Правила

- Ошибка ассерта пишется по-русски и содержит **числа**: не «слишком долго»,
  а «планирование заняло 320 мс».
- Тесты чистой логики не должны требовать дерева сцены.
- `0 orphans` в сводке — часть зелёного прогона, а не деталь.
